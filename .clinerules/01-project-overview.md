# Project Overview

- **Project:** `patient-engagement` — a Solution Reach style patient engagement platform.
- **Features:** Campaigns, Newsletters, Surveys, Email Templates, Reviews, Direct two-way texting.
- **Core screens:** Login, Member registration, Main dashboard, Campaign dashboard.
- **Stack:** Next.js (App Router, TypeScript), PostgreSQL, Drizzle ORM, pnpm, lucide-react icons, CSS Modules.
- **UI goal:** Modern, clean, intuitive, responsive, accessible. Use plain, consistent spacing and a calm healthcare-friendly color palette defined as CSS variables.
