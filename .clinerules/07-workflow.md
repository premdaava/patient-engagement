# Workflow Rules

- Work on **one task at a time**. Before coding, give a short plan listing the files you will create or change.
- Do **not** install packages that are not needed. Do **not** refactor unrelated code.
- After each task: run `pnpm lint`, fix errors, then summarize what changed.
- **Ask** before making destructive changes (deleting files, resetting the database, changing the schema in a breaking way).
